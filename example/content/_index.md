Welcome. This site is built from a directory of Markdown files by `staticgen`.

Everything you see — the navigation, the tag pages, the archive, the RSS feed and
the search index — is derived from the files in `content/` and the settings in
`site.yaml`.

## What is here

The [blog](/blog/) collects longer posts. The [about](/about/) page is a plain
standalone Markdown file with no section, which shows how root-level pages work.
