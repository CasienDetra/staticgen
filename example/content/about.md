## Colophon

The site is generated by a Go program. Markdown is parsed with
[goldmark](https://github.com/yuin/goldmark), code blocks are highlighted with
[chroma](https://github.com/alecthomas/chroma), and pages are assembled with the
standard library's `html/template`.
