កម្មវិធីបង្កើតគេហទំព័រ static មានភារកិច្ចសំខាន់មួយ គឺអានឯកសារ
Markdown ហើយបង្កើតឯកសារគេហទំព័រ។

<!--more-->

## ការបង្កើតគេហទំព័រ

ដំណើរការពាក្យបញ្ជាខាងក្រោមពីថតគម្រោង៖

```bash
staticgen build --source ./example
```

កម្មវិធីនឹងអានឯកសារនៅក្នុង `content/` និង `content/km/` បន្ទាប់មកបង្កើត
ទំព័រភាសាអង់គ្លេសនៅ `/` និងទំព័រភាសាខ្មែរនៅ `/km/`។

## ការប្តូរភាសា

ដោយប្រើ `translation_key` ដូចគ្នា ទំព័រទាំងពីរនឹងបង្ហាញតំណសម្រាប់ប្តូរភាសា
នៅក្នុងក្បាលទំព័រ។
